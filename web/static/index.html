Loss

The dashed line is ln(vocab_size): the loss of a model that has learned nothing. Everything below it is real learning. When the orange line turns back up while the blue keeps falling, the model has started memorising instead of generalising.

Attention

Row i is what token i attended to. The empty upper triangle is the causal mask: a token can never see the future, which is the property that makes next-token training honest.
